# Changelog

Все заметные изменения EasyTizen. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел версии целиком попадает в описание релиза на GitHub.

## [0.9.5] — 2026-11-15

Один встроенный движок вместо загрузки Tizen SDK, надёжный поиск телевизоров и точная диагностика подключения. В релизе — по одному файлу на систему.

> [!IMPORTANT]
> **Ничего докачивать не нужно:** Tizen SDK, Tizen Studio и Node.js больше не используются — EasyTizen работает сразу после установки.
>
> **Обновление с 0.9.1:** Windows, macOS и AppImage обновятся из приложения. На **Android** 0.9.1 один раз скачайте `EasyTizen-Android.apk` вручную (поверх старой версии, данные сохранятся). Если EasyTizen стоял из **`.deb`** — удалите его (`sudo apt remove easy-tizen`) и запустите `EasyTizen-Linux-x64.AppImage`. На **macOS** старые установки обновятся сами; новым пользователям — один файл `EasyTizen-macOS.app.tar.gz` для Apple и Intel.
>
> Сертификаты, созданные в 0.9.x через Tizen SDK, переносятся один раз: «Сертификаты» → «Перенести». Установка на **физический телевизор Samsung** и на **реальном Android-устройстве** по-прежнему не подтверждены автором — см. известные ограничения.

### Удалено
- **Загрузчик Tizen SDK и режим «Официальные инструменты Samsung».** Больше не скачиваются Tizen SDK и Samsung TV Extension (~15 ГБ), не встраивается Node.js и копия Samsung CLI, нет экрана выбора движка, подготовки инструментов, очередей и кэша загрузок, проверок места на диске. Удалены модули `sdk_engine`, `sdk_installer`, `toolchain`, `easytizen-core::samsung`, папка `resources/`, скрипты `fetch-node.mjs` и `vendor-samsung-cli.sh`, соответствующие шаги CI, настройки и тексты. Приложение не запускает дочерних процессов.

### Изменено
- **Релиз — один файл на систему**: `EasyTizen-Android.apk`, `EasyTizen-Windows-x64-Setup.exe`, `EasyTizen-macOS.app.tar.gz` (один универсальный для Apple и Intel), `EasyTizen-Linux-x64.AppImage` и служебный `latest.json` для автообновления. Больше не публикуются два `.dmg`, `.deb`, отдельные `.sig` и `SHA256SUMS.txt`: подписи и контрольная сумма APK — внутри `latest.json`, таблица SHA-256 — в описании релиза. Установленные версии 0.9.x на компьютере обновятся сами; Android 0.9.x и установки из `.deb` один раз предложат скачать новую версию вручную.

### Новое
- **Поиск телевизоров** по всем активным сетевым интерфейсам (Wi-Fi, Ethernet; VPN, виртуальные адаптеры и мобильный интернет пропускаются), параллельный опрос портов `26101` (SDB) и `8001` (служба Samsung), SSDP-запрос и повторная проверка сохранённых телевизоров. Найденные ТВ появляются по мере обнаружения с названием, моделью, версией Tizen и статусом: «Готов к установке», «Developer Mode выключен», «Неверный Host PC IP». Отмена, таймауты, повторы, удаление дубликатов.
- **Проверка подключения по шагам**: сеть этого устройства, та же ли сеть, ответ телевизора, Developer Mode, Host PC IP, порт установки, приём подключения — список «Что проверено» и пошаговые инструкции. Developer Mode и Host PC IP читаются у самого телевизора; недостоверные выводы не делаются.
- Блок **«Host PC IP для телевизора»** с адресом этого устройства (на Android — адрес телефона), обновляется при возврате в приложение.
- **Сохранённые телевизоры**: смена адреса, проверка доступности, модель и версия Tizen.
- **Проверка результата установки** по списку приложений телевизора; процент установки сообщает сам телевизор. Если каталог загрузки отклонён, используется запасной; загруженный файл удаляется с телевизора и после обрыва связи или отмены.
- **Перенос сертификатов**, созданных через Tizen SDK прежними версиями: страница «Сертификаты» → «Перенести» (исходные файлы не изменяются).
- **Журнал** `logs/easytizen.log` (без секретов) и кнопка «Папка с журналом»; конец журнала входит в отчёт диагностики.

### Исправлено
- Windows: приложение запускалось с чёрным консольным окном — теперь это GUI-программа (`windows_subsystem = "windows"`), CI проверяет подсистему исполняемого файла.
- Телевизор, не ответивший на `capability:`, получал команды не для ТВ (`pkgcmd`) — теперь используется набор команд телевизора.
- Разрыв соединения телевизором («Host PC IP не совпадает») показывался как общая сетевая ошибка — теперь отдельная понятная причина.
- Поиск охватывал только одну подсеть /24 основного интерфейса и находил лишь телевизоры с уже включённым режимом разработчика.

## [0.9.1] — 2026-11-14

Новый интерфейс, автоматические обновления и отключаемая дополнительная проверка приложений.

> [!IMPORTANT]
> **Обновиться на 0.9.1 нужно вручную** — версия 0.9.0 не умеет обновляться сама. Начиная с 0.9.1 новые версии EasyTizen будут устанавливаться из приложения.
>
> **Android:** APK 0.9.0 был подписан временным ключом, поэтому 0.9.1 не встанет поверх него — сначала удалите старую версию (созданные в ней сертификаты при этом удаляются: создайте их заново или импортируйте файлы `.p12`). Дальше обновления подписаны постоянным ключом проекта.
>
> Установка на **физический телевизор Samsung** и работа на **реальном Android-устройстве** по-прежнему не подтверждены — см. известные ограничения.

### Новое
- **Автоматические обновления.** Настройки → «Обновления приложения»: переключатель автоматической проверки и установки, текущая версия, время последней проверки, кнопка «Проверить сейчас», размер и список изменений новой версии. На компьютере обновление скачивается из официального GitHub Releases, его подпись проверяется ключом проекта (Tauri updater), а применяется оно при перезапуске — с подтверждением и никогда во время установки на телевизор. На Android APK сверяется с `SHA256SUMS.txt` (и подписью, если сборка содержит ключ) и передаётся системному установщику. Выключенный режим не делает фоновых запросов.
- **Дополнительная проверка безопасности приложений** (Настройки → «Безопасность», включена по умолчанию): ID приложения, стартовая страница, исполняемые программы для других систем, повторяющиеся имена файлов, совпадение имеющейся подписи при установке без переподписи. Пакет с проблемами не устанавливается. Отключение требует подтверждения, а каждая установка без этих проверок — явного согласия. Обязательная защита (Zip Slip, zip-бомбы, лимиты размера, повреждённые архивы, XML без DTD) работает всегда.

### Изменено
- Новый интерфейс на единой дизайн-системе (`docs/DESIGN-SYSTEM.md`): токены цветов, радиусов, типографики и теней; встроенный шрифт Inter 4 с кириллицей; обзор шагов установки; панель «Проверка пакета»; экран успеха со ссылкой на историю.
- Android: четыре вкладки внизу (История — в верхней панели), зоны нажатия от 44 px, безопасные области, нижние листы вместо диалогов, длинные имена, IP и DUID больше не обрезаются; приложение следует системному размеру шрифта.
- Доступность: видимый фокус клавиатуры, ловушка фокуса в диалогах, подписи у кнопок-иконок, переключатели на всю строку, состояния не только цветом.
- README: крупные кнопки «Русская версия / English version», скриншоты на языке README.

## [0.9.0] — 2026-11-14

Первый выпуск под названием **EasyTizen** (раньше — TV Deploy) и первая версия для Android.

> [!IMPORTANT]
> Это предварительный выпуск. Автоматические тесты пройдены, но установка на **физический телевизор Samsung** и работа на **реальном Android-устройстве** ещё не подтверждены — см. «Известные ограничения». Версия 1.0.0 выйдет после такой проверки.

### Новое

- **Приложение для Android.** Самостоятельный установщик: поиск телевизора, подключение, получение DUID, выпуск сертификата Samsung, проверка, подписание и установка `.wgt` прямо с телефона — без компьютера, Tizen SDK и Termux.
- **Встроенный движок** (Android и, по выбору, компьютер): собственная реализация протокола SDB, подписание WGT (XML-DSig) и выпуск сертификатов через Samsung CA. Tizen SDK для него не нужен.
- **Установка Tizen SDK с прогрессом:** этапы и счётчик пакетов, отмена всего дерева процессов, продолжение прерванной установки, выбор папки и проверка свободного места до загрузки.
- **Менеджер сертификатов:** создание для одного или нескольких телевизоров, импорт готовой пары `author.p12` + `distributor.p12`, срок действия, удаление.
- **Менеджер телевизоров:** сохранённые устройства, переименование, копирование DUID, дата последнего подключения.
- **История установок** и **отчёт диагностики** (без паролей и ключей) с копированием и сохранением в файл.
- **Проверка обновлений** EasyTizen при запуске с прямой ссылкой на установщик для вашей платформы.
- **Мастер первого запуска** и встроенная инструкция по режиму разработчика с подставленным адресом для Host PC IP.
- Установка уже подписанного пакета без переподписания; удаление старой копии приложения с телевизора при конфликте автора (встроенный движок).
- Новый интерфейс: боковая и нижняя навигация, пошаговый прогресс установки, уведомления, пустые состояния, светлая/тёмная/системная темы, русский и английский языки.

### Изменено

- Продукт переименован в EasyTizen: новое имя, значок, идентификатор `io.github.volnalabs.easytizen`. Настройки, сохранённые телевизоры и профили сертификатов TV Deploy переносятся автоматически при первом запуске; Tizen SDK и его хранилище ключей не затрагиваются.
- Профиль сертификата может покрывать несколько телевизоров (несколько DUID).
- Файлы релиза получили постоянные имена: `EasyTizen-Android.apk`, `EasyTizen-Windows-x64-Setup.exe`, `EasyTizen-macOS-ARM64.dmg`, `EasyTizen-macOS-Intel.dmg`, `EasyTizen-Linux-x64.AppImage`, `EasyTizen-Linux-x64.deb`.

### Исправлено

- Отмена установки SDK останавливала только оболочку установщика, а загрузки продолжались в фоне.
- Рабочие копии подписанных пакетов не удалялись после установки и при сбоях.
- Ошибки установки показывались кодом без объяснения; теперь — понятный текст и подробности телевизора.
- Прерванное создание сертификата после выпуска сертификата автора приходилось начинать заново.

### Известные ограничения

- **Не проверено на оборудовании:** подключение, получение DUID, вход в Samsung Account, выпуск сертификата и установка проверены автоматическими тестами на эмуляторе телевизора и локальной замене Samsung CA, но не на физическом телевизоре и не на реальном телефоне.
- **Встроенный движок — экспериментальный.** Его подписи проверяются независимым `xmlsec1`, протокол сверен с официальным `sdb` 4.2.36, но приём пакета настоящим телевизором предстоит подтвердить. На компьютере по умолчанию используются официальные инструменты Samsung.
- **Android:** вход в Samsung проходит через браузер с возвратом на `localhost`; на прошивках с агрессивной «заморозкой» фоновых приложений после входа нужно вручную вернуться в EasyTizen. Сертификаты нельзя перенести между встроенным движком и Tizen SDK без импорта файлов `.p12`.
- **Пароль сертификата** во встроенном движке запрашивается один раз за запуск приложения и не сохраняется.
- **macOS:** установщику Tizen SDK нужен Bash 4+ (`brew install bash`).
- Обновление EasyTizen — это проверка новой версии и ссылка на установщик; автоматической тихой установки нет.
- Проверка подписи выбранного файла до установки — структурная; окончательное решение принимает телевизор.

## [0.1.0] — 2026-11-13

Публичная предварительная версия под названием TV Deploy: настольное приложение (Windows, macOS, Linux) на официальных инструментах Samsung — подготовка Tizen SDK, поиск и подключение телевизора, DUID, создание сертификата, проверка, подписание и установка WGT.
